Проект автоматизации тестирования веб-приложения Доставка самоката
Данный проект содержит автоматизированные UI-тесты для веб-приложения (https://qa-scooter.praktikum-services.ru/). 
Тесты покрывают следующие пользовательские сценарии: 
1) Выпадающий список в разделе «Вопросы о важном»., открывается соответствующий текст.
2) Заказ самоката (два набора данных с думя точками входа) 
Позитивный сценарий:
Нажать кнопку «Заказать». На странице две кнопки заказа.
Заполнить форму заказа.
Проверить, что появилось всплывающее окно с сообщением об успешном создании заказа.
Проверить: если нажать на логотип «Самоката», попадёшь на главную страницу «Самоката».
Проверить: если нажать на логотип Яндекса, в новом окне через редирект откроется главная страница Дзена.

Требования к окружению
Установленный Python версии 3.8 или выше.
Браузер Firefox (рекомендуется последняя стабильная версия).
geckodriver, соответствующий версии Firefox
Чтобы запустить Allure, нужна среда разработки Java. Установка JDK


Установить в vs code (терминал):
Установка pytest
pip install pytest

Установка Selenium
pip install selenium

Установка allure
pip install allure-pytest


Allure отчеты
Чтобы сгенерировать Allure-отчёт, введи в терминале Vs Code:
pytest tests.py --alluredir=allure_results

Теперь нужно сформировать отчёт в формате веб-страницы. Напиши в терминале Vs Code:
allure serve allure_results

Сформируется HTML-файл: по умолчанию он будет лежать в директории с установленным Allure. Запустится веб-сервер Allure, и в браузере откроется вкладка с результатами тестов.

Файл с внешними зависимостями
Создать файл requirements.txt Этот файл — список внешних зависимостей.Обычно команду выполняют перед отправкой кода в репозиторий.
Если при доработке проекта появился новый импорт, используй команду снова. Она обновит файл.
pip freeze > requirements.txt

Как установить зависимости из файла
pip install -r requirements.txt

Запуск тестов
pytest -v tests/ --alluredir=allure_results

Проект:
conftest.py — глобальные фикстуры pytest:
requirements.txt - список внешних зависимостей
test/test_main_page.py - Тест Проверка текста ответа на вопрос из FAQ (Все вопросы) 
test/test_order_scooter.py -Позитивный тест создание заказа с разными точками входа и 2 наборами данных + Проверка логотипа Самоката - возвращает на главную страницу. Проверка логотипа Яндекса (открытие новой вкладки с Dzen)
pages/ - страницы с описанием методов и функций
locators/страницы с описанием локаторов, содержит кортежи локаторов (By, селектор)

Примечания
Во всех тестах используются явные ожидания (WebDriverWait) с таймаутами 3–5 секунд для обеспечения стабильности.
